🔧 STEP 1: FIX CODE (30 MENIT)
═══════════════════════════════════════════════════════════════

1. Buat file: frontend/.env.local
   ────────────────────────────────
   NEXT_PUBLIC_API_URL=http://localhost:8000

2. Update: backend/app/main.py
   ────────────────────────────────
   Tambahkan setelah app = FastAPI():

   from fastapi.middleware.cors import CORSMiddleware
   
   app.add_middleware(
       CORSMiddleware,
       allow_origins=[
           "http://localhost:3000",
           "https://*.vercel.app",  # Ganti nanti
       ],
       allow_credentials=True,
       allow_methods=["*"],
       allow_headers=["*"],
   )

3. Update: backend/requirements.txt
   ────────────────────────────────
   fastapi==0.115.0
   uvicorn[standard]==0.32.0
   python-multipart==0.0.12
   ultralytics==8.3.0
   opencv-python-headless==4.10.0.84
   pillow==11.0.0
   numpy==1.26.4
   python-dotenv==1.0.1

4. Commit & Push ke GitHub
   ────────────────────────────────
   git add .
   git commit -m "Prepare for deployment"
   git push

═══════════════════════════════════════════════════════════════
🚂 STEP 2: DEPLOY BACKEND - RAILWAY (30 MENIT)
═══════════════════════════════════════════════════════════════

1. Buka: https://railway.app
2. Login dengan GitHub
3. Klik "New Project" → "Deploy from GitHub repo"
4. Select repository kamu
5. Railway auto-detect Python → Klik "Deploy"
6. Tunggu build selesai (~5 menit)
7. Buka Settings → Networking → Generate Domain
8. Copy URL: https://oceanguard-backend.railway.app

✅ TEST: Buka https://oceanguard-backend.railway.app/docs
   (Harus muncul Swagger UI!)

═══════════════════════════════════════════════════════════════
🎨 STEP 3: DEPLOY FRONTEND - VERCEL (30 MENIT)
═══════════════════════════════════════════════════════════════

1. Update frontend/.env.local:
   ────────────────────────────────
   NEXT_PUBLIC_API_URL=https://oceanguard-backend.railway.app

2. Commit & Push:
   ────────────────────────────────
   git add .
   git commit -m "Update API URL for production"
   git push

3. Buka: https://vercel.com
4. Login dengan GitHub
5. Klik "Add New Project"
6. Import repository kamu
7. Vercel auto-detect Next.js
8. Klik "Deploy"
9. Tunggu build selesai (~3 menit)
10. Copy URL: https://oceanguard.vercel.app

✅ TEST: Buka https://oceanguard.vercel.app
   (Harus muncul homepage!)

🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ CORS Error:
   → Check allow_origins di backend/app/main.py
   → Pastikan frontend URL benar
   → Redeploy backend

❌ Model Not Found:
   → Pastikan best.pt ada di repository
   → Check .gitignore (jangan ignore *.pt)
   → Push ulang

❌ Railway Out of Memory:
   → Gunakan YOLOv8 Nano (bukan Small)
   → Sudah benar? Good!
