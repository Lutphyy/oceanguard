🔧 Improvement yang Harus Dilakukan

1. Fix API URL (CRITICAL!)

⚠️ MASALAH: API URL hardcoded ke localhost:8000, tidak bisa diakses setelah deploy!

Solusi: Gunakan environment variable

File: frontend/.env.local (buat file baru)

# Development
NEXT_PUBLIC_API_URL=http://localhost:8000

# Production (ganti setelah deploy backend)
# NEXT_PUBLIC_API_URL=https://your-backend.railway.app

File: frontend/app/page.js (sudah benar, tidak perlu diubah)

const API_URL = process.env.NEXT_PUBLIC_API_URL || "http://localhost:8000";

2. Fix CORS di Backend (CRITICAL!)

File: backend/app/main.py

Tambahkan CORS middleware:

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI(title="OceanGuard API")

# CORS Configuration
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:3000",  # Development
        "https://your-frontend.vercel.app",  # Production (ganti setelah deploy)
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

3. Add Environment Variables

File: backend/.env (buat file baru)

# Model Configuration
MODEL_PATH=../model/weights/best.pt
CONFIDENCE_THRESHOLD=0.25
IOU_THRESHOLD=0.45

# API Configuration
API_HOST=0.0.0.0
API_PORT=8000

4. Update requirements.txt

File: backend/requirements.txt

Pastikan semua dependencies ada:

🚀 STEP 1: Deploy Backend ke Railway

A. Persiapan

  1. Buat akun di railway.app
  2. Login dengan GitHub
  3. Push code ke GitHub repository

B. Deploy

  1. Klik "New Project"
  2. Pilih "Deploy from GitHub repo"
  3. Select repository kamu
  4. Railway akan auto-detect Python project
  5. Klik "Deploy"

C. Konfigurasi

  1. Buka Settings → Environment Variables
  2. Tambahkan: 
    PORT=8000
PYTHON_VERSION=3.10
  3. Buka Settings → Networking
  4. Generate domain (contoh: oceanguard-backend.railway.app)
  5. Copy URL ini!
✅ Backend URL: https://oceanguard-backend.railway.app
Test: Buka https://oceanguard-backend.railway.app/docs (harus muncul Swagger UI)

🚀 STEP 2: Deploy Frontend ke Vercel

A. Persiapan

  1. Update frontend/.env.local: 
    NEXT_PUBLIC_API_URL=https://oceanguard-backend.railway.app
  2. Commit & push ke GitHub

B. Deploy

  1. Buka vercel.com
  2. Login dengan GitHub
  3. Klik "Add New Project"
  4. Import repository kamu
  5. Vercel auto-detect Next.js
  6. Klik "Deploy"

C. Konfigurasi Environment Variable

  1. Buka Settings → Environment Variables
  2. Tambahkan: 
    NEXT_PUBLIC_API_URL=https://oceanguard-backend.railway.app
  3. Klik "Save"
  4. Redeploy (Settings → Deployments → Redeploy)
✅ Frontend URL: https://oceanguard.vercel.app
Test: Upload gambar dan cek apakah deteksi jalan!

🚀 STEP 3: Update CORS di Backend

Setelah dapat URL frontend, update backend/app/main.py:

allow_origins=[
    "http://localhost:3000",
    "https://oceanguard.vercel.app",  # ← Ganti dengan URL kamu!
]

Commit, push, dan Railway akan auto-redeploy!

🚨 Troubleshooting

Problem: CORS Error

Error: Access to fetch at '...' from origin '...' has been blocked by CORS policy

Solution:

  1. Check CORS middleware di backend/app/main.py
  2. Pastikan frontend URL ada di allow_origins
  3. Redeploy backend

Problem: Model Not Found

Error: FileNotFoundError: model/weights/best.pt

Solution:

  1. Pastikan best.pt ada di repository
  2. Check .gitignore (jangan ignore *.pt)
  3. Push ulang ke GitHub

Problem: Railway Out of Memory

Error: Killed (OOM)

Solution:

  1. Gunakan YOLOv8 Nano (bukan Small/Medium)
  2. Reduce batch size di inference
  3. Upgrade Railway plan (kalau perlu)
